# msxxyfero-shopify — Muse + Codex 协作

Shopify 店 Msxxyfero（msxxyfero.com）的协作仓库。GitHub 为主，Google Drive 放图片。

## 分工
- **Muse (SUMMER)：** 持续对话、规划、选题、核实事实、验 live 页、记进度。
- **Codex（用户电脑上）：** 代码、本地操作、内置生图、生成 + 发布 Blog。
- 两人不能实时对话，靠这个仓库来回传：Muse 写 brief → Codex 执行并回传结果 → Muse 验 live。

## 目录
- `muse-codex-daily-blog-brief.md` — 协作总 brief：分工、循环、硬规则、已有文章、下篇选题
- `briefs/` — 每天一篇的 brief，文件名按日期，如 `2026-11-07-...md`
- `articles/` — Codex 生成的文章草稿（Markdown），发布后在文件头补 Live URL
- `status.md` — 当前状态：做到哪了、下一步是谁
