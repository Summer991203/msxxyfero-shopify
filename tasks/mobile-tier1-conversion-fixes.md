## 做这三项（只做这三项，不要顺手加别的）

### 1. 手机端吸底购买条（最重要）

- 只在手机端显示（max-width: 768px），桌面端不动。
- 行为：页面顶部时不显示；当主购买区（Add to cart 按钮）滑出视野后出现；滑回购买区时隐藏。不要一直悬着挡内容。
- 内容（紧凑，单行/两行）：商品短名 + 当前选中颜色/件数 + 总价 + 一个深绿 "Add to cart" 按钮（用现有按钮样式、颜色、字体，保持整体性）。
- 点击效果：按组件当前所选变体与套餐件数加购（和主按钮同一逻辑），加购后打开购物车抽屉/页面。不要在吸底条里再放 PayPal 按钮（PayPal iframe 初始化本来就慢，重复放会出问题；主购买区已有金色 PayPal 按钮）。
- 必须跟套餐组件状态同步：改颜色、改件数后，吸底条的价格/件数要跟着变（复用组件现有的同步逻辑）。
- 三个商品页都要有。

### 2. 购买区加真实送达日期（三页）

- 现状：信任行写 "Free standard shipping · US delivery ~7 days"，没有任何日期。
- 改法：把这行改成 "Free standard shipping · Est. delivery before [日期]"，日期 = 今天 + 7 天（标准约 7 天、当天发货），**动态计算**，不要写死（Liquid 或 JS 算，格式如 "Nov 14"）。
- 不要重复：只改这一行，别在旁边再加一行日期。三个商品页的对应文案都改。
- 诚实口径：标准配送约 7 天；不要承诺加急，不要写 "guaranteed"。

### 3. 星级 + 评价数移到标题上方（只改钥匙扣、睡袋）

- 现状：星级在标题下方。
- 改法：把 Judge.me 的星级 + 评价数移到标题正上方（参考 Litter-Robot）。只移动现有组件的输出，不要改数字、不要编造评价。
- 猫球页 0 评价：不动（保持 "Be the first to write a review"）。
